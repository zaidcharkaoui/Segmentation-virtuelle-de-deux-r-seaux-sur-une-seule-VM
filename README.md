# Segmentation-virtuelle-de-deux-r-seaux-sur-une-seule-VM
Projet de segmentation de réseaux virtuels utilisant un contrôleur Web inspiré du SDN, Python et Open vSwitch (OVS) pour créer et gérer deux réseaux isolés, attribuer des adresses IP et contrôler les communications entre les réseaux grâce à des règles de filtrage, le tout sur une seule machine virtuelle Linux. (Ubuntu server en test reel)
